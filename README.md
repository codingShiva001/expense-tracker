# 📌 Expense Tracker App

A simple and interactive **Expense Tracker web application** built using HTML, CSS, and JavaScript.  
It helps users track their income and expenses in a clean and minimal UI.

---

## 🚀 Live Demo
https://sd-expense-tracker.netlify.app/

---

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla JS)

---

## ✨ Features
- Add income and expenses
- Real-time balance calculation
- Clean and responsive UI
- Simple and easy to use
